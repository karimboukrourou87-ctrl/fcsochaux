Code de la fiche

Bienvenue sur votre tableau CPA

  1. Choisissez un modèle (corner, coup franc…) ou partez d'un terrain vide.
  2. Touchez ＋ Joueurs pour en ajouter, puis glissez les avec le doigt.
  3. Touchez Course en bas, puis glissez depuis un joueur pour dessiner sa course. Ballon fait pareil pour le ballon.
  4. Touchez Jouer pour voir l'action bouger, puis Imprimer pour faire la fiche.

Astuce : un doigt sur le gazon fait tourner la vue, deux doigts zooment. La flèche ↶ annule la dernière action.
